# Garage Tuning - Despliegue de Aplicación Web con Nginx

Aplicación web desarrollada para la gestión, información técnica y servicios de un taller automotriz de alto rendimiento (*Garage Tuning*). Este proyecto forma parte de los entregables prácticos para la organización, empaquetado, versionamiento y despliegue en un entorno de simulación de servidor web local.

## 🛠️ Tecnologías y Herramientas Utilizadas
* **HTML5 / CSS3 / JavaScript (ES6):** Estructura semántica, diseño responsivo y lógica interactiva del cliente.
* **Nginx:** Servidor web HTTP independiente para la simulación y despliegue en entorno local.
* **Git & GitHub:** Control de versiones, historial de commits atómicos y gestión del repositorio.
